# Food-Recipe-app
# 🍲 Food Recipe App

A responsive **Food Recipe App** built using **HTML**, **CSS**, **Bootstrap** and **JavaScript**. Users can browse recipes by cuisine with one click, or search for a recipe by name.

---

## 🔗 Live Demo

👉 **[https://food-recipe-sneha.netlify.app](https://food-recipe-sneha.netlify.app)**

---

## ✨ Features

- Dark themed, clean recipe listing page
- Cuisine filter buttons: **Indian, Canadian, American, Thai, British, Russian**
- Search box to find recipes quickly
- Recipes rendered dynamically using JavaScript
- Responsive layout using Bootstrap 5
- Lightweight, no build tools needed

---

## 🛠️ Tech Stack

| Technology | Use |
|------------|-----|
| HTML5 | Page structure |
| CSS3 | Custom styling |
| Bootstrap 5.3 | Responsive layout and buttons |
| JavaScript (ES6) | Dynamic rendering, filtering and search |
| Netlify | Deployment |

## 🚀 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/sneha-goyal7/Food-Recipe-app.git
   ```
2. Open the project folder
   ```bash
   cd Food-Recipe-app
   ```
3. Open `index.html` in your browser (or use **Live Server** in VS Code)
